凌美会 管理画面 ヘルプ

管理画面で困ったときに読むページです。使い方は、管理画面の各見出しの横にある「？」を押すと確認できます。

管理画面を開く
  • エラーが出たとき
  • ログインできない
  • 公開・下書き
  • 画像・展示会
  • 管理者への連絡

エラーが出たとき

エラーの読み方と、管理者への伝え方

エラーは「〇〇ができませんでした。」で始まる1行で表示され、続けて、まず試してほしいことが書かれています。途中で切れているときは、横の「詳細」を押すと、すぐ下に全文が開きます。

  • 案内どおりに試しても解決しないときは、「詳細」で開いたカードの「エラー内容をコピー」を押し、メールや LINE に貼り付けて管理者に送ってください。エラーの番号・日時・操作・内容がまとめてコピーされます。
  • 「詳細」を押さなくてもカードが開いたときは、システム側の問題です。設定によっては管理者に自動でメールが届きます。カードに「通知しました」と出ていなければ、コピーして連絡してください。
  • 少し前のエラーは、画面上部の「履歴」から見返してコピーできます。
  • コピーがうまくいかないときは、カードの「報告用の内容を表示」を開き、出てきた文章を選んでコピーしてください。

ログインできない

「現在、ファイルを開くことができません。」と表示される

ブラウザに複数の Google アカウントでログインしているときによく起きます。次の順に試してください。

  1. Chrome のゲストモードで管理画面の URL を開く（いちばん確実です）
  2. シークレットウィンドウ（Edge では InPrivate ウィンドウ）で開く
  3. ブラウザの Cookie を削除してから開き直す
  4. アカウントを選んで開くリンクを開き、表示されるアカウントを順番に試す
「このメールアドレスにはアクセス権がありません」と表示される

入力したメールアドレスが、管理画面を使える人の一覧に入っていません。打ち間違いがないか確かめ、それでも出る場合は管理者に追加を頼んでください。

確認コードのメールが届かない
  1. 迷惑メールのフォルダを確認する
  2. 入力したメールアドレスが正しいか確認する
  3. 数分待ってから、もう一度「確認コードを送信」を押す

確認コードの送信は、同じメールアドレスに1時間で5回までです。「送信回数が上限に達しました」と出たら、しばらく時間をおいてください。確認コードの有効期限は10分で、5回間違えると使えなくなります。そのときは新しいコードを送ってください。

「セッションが切れています。もう一度認証してください。」と表示される

ログインしてから180分たつと、ログインが切れます（操作していても延びません）。ページを再読み込みして、もう一度ログインしてください。

長い作業の途中では、こまめに「下書き保存」してください。

公開・下書き

公開したのにホームページに反映されない

「公開する」を押してから反映されるまで、数分かかります。少し待ってから、ホームページを再読み込みしてください。10分ほど待っても変わらないときは、管理者に連絡してください。

「非公開」になっている項目は、公開してもホームページには出ません。項目の見出しの下が「公開中」になっているか確認してください。

保存した下書きが消えた

誰かが「公開する」を押すと、その時点の内容がホームページに出ると同時に、全員の下書きが消えます。何人かで作業するときは、公開の前に声をかけ合ってください。

「入力が長すぎます。」と表示される

どこかの項目が、入力できる文字数を超えています。長い文章の項目（概要・本文など）を短くしてから、もう一度保存してください。どの項目かわからないときは、管理者に連絡してください。

画像・展示会

管理画面の画像に「画像を表示できません」と出る

アップロードした直後は、Google Drive の準備が終わっておらず、表示できないことがあります。少し待ってから、ページを再読み込みしてください。何度試しても表示されないときは、管理者に連絡してください。

アップロードした画像が「画像の設定」に表示されない

「画像の設定」をいったん閉じて、もう一度開いてください。

展示会の作品写真がホームページに出ない

展示会が「公開中」になっているか確認してから、「公開する」を押してください。「非公開」のままでは、作品写真も表示されません。

手で直した会期表示が元に戻った

会期表示は、開始日・終了日から自動で作られます。開始日か終了日を変えると、手で直した内容は日付から作り直されます。日付を決めてから、最後に会期表示を直してください。

ホームページの住所を押すと、違う場所の地図が開く

住所のリンクは、会場名と住所で Google マップを検索しています。会場名や住所を、建物名や番地まで正確に書き直してください。管理画面の右側のプレビューでも、住所を押して確かめられます。

活動場所・年間スケジュール・紹介文などを変えたい

これらは管理画面からは変更できません。管理者に変更を頼んでください。

管理者への連絡

このページで解決しないときは、管理者に連絡してください。エラーが出ている場合は、「エラー内容をコピー」でコピーした文章を貼り付けてもらえれば、下の③と④は不要です。

  1. 何をしようとしたか
  2. どのボタンを押したか
  3. 表示されたメッセージ（スクリーンショットがあると助かります）
  4. 起きた日時
